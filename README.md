

# TaskFlow – Project Management SaaS

## About the Project
TaskFlow is a modern and responsive project management SaaS landing page designed to help individuals and teams organize tasks, manage projects and improve productivity.

## Features
- Modern responsive navigation bar
- Professional hero section with dashboard preview
- Six feature cards
- About and How It Works section
- Starter and Professional pricing plans
- Contact and demo request form
- JavaScript form validation
- Mobile responsive design
- Smooth navigation

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## How to Run
1. Download or clone this repository.
2. Open the TASKFLOW folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Explore the TaskFlow website.
